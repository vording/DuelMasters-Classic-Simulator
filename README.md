# デュエマ System

デュエル・マスターズのデッキ作成・一人回し・ネット対戦ができる静的 Web アプリです（非公式のファンツール）。
**クラシック基本編（DM-01〜05・DMC-01〜04 と同時期のプロモ）のカード365種が収録済み**です（`classic-cards.js`）。ルールはクラシック基本編だけです。ブラウザ内（localStorage）に保存するのはデッキと設定だけです。

`index.html` を開くだけで動きます（サーバー不要。GitHub Pages などにそのまま置けます）。

## 収録カード
- 基本編のカードを、[デュエル・マスターズ公式サイトのカード検索](https://dm.takaratomy.co.jp/card/)から取得しました（同名カードは1種類にまとめ、最初に収録された弾を「収録」にしています）
- 画像は公式サイトの画像を直接表示します（アプリには画像を入れていません。表示にはネット接続が必要）。読み込むまでは、文明の色の枠にコスト・名前・パワーを書いたカードを出します
- 公式サイトのサイトポリシーでは、個人的な使用や非営利目的の使用は認められています。それ以外の目的で使ったり、データを再配布したりする場合は権利者の許諾が必要です
- カードの登録・編集の機能はありません（収録カードだけを使います）

## 殿堂（クラシック基本編）
- 制限（1枚まで）・禁止（0枚）の既定の一覧が入っています（`cards.js` の `REGULATION`）。クラシックの殿堂はコミュニティで決められた非公式のもので、改定されたら「殿堂…」で書き換えられ、「既定に戻す」で戻せます
- カード一覧とデッキリストで、制限のカードに「殿堂」、禁止のカードに「禁止」の小さな印を付けます。禁止のカードはカード一覧で暗く表示します

## スタート画面（index.html を開いたとき）
- 真っ暗な画面に、ふわふわ浮かんでゆっくり点滅するロゴと、その下で点滅する「TOUCH START」だけ。画面のどこを押してもスタート（Enter・スペースでも）
- 押すと、光の輪と火花が広がり、画面が光ってロゴが手前に飛んでくる → ワイプでデッキ選択へ。BGM もここから流れる
- 一度スタートしたら、そのタブでは出さない（対戦から戻ったときなど）。上のロゴを押すとスタート画面に戻る

## デッキ選択（スタート画面の次）
- 開くとまずデッキ選択。デッキごとに表紙（一番コストの大きいクリーチャー）・名前・枚数（40枚なら緑）・文明を表示
- デッキを押す（または「編集」）と編集画面へ（URL は `index.html#edit=デッキID`）。「対戦 ▶」でそのデッキで一人回し・対戦へ。「＋ 新しいデッキ」「インポート…」もここから
- 編集画面の「◀ デッキ選択に戻る」、ブラウザの戻る、上部の「DECK BUILD」でデッキ選択に戻る

## デッキ作成（index.html の編集画面）
- カードを左クリック（スマホはタップ）で1枚追加、右クリックで1枚減らす。長押ししているあいだ詳細を表示（離すと閉じる）。マウスを乗せただけでは何も出ない。デッキリストのカード名も同じ操作
- 40枚ちょうど・同じカードは4枚まで・殿堂（違反は警告）
- 文明ごとの枚数、内訳（S・トリガー・ブロッカー・クリーチャー・呪文・その他の枚数）、コストの分布を表示
- デッキリストの並び順：種類順・コスト順・文明順（デッキごとに記憶）。リストは右側のパネルの中でスクロール
- キーカード：デッキリストのカード名の左の ☆ を押すとキーカード（★）になり、デッキ選択の表紙に出す（もう一度押すと解除。設定していないか、デッキから抜いたときは一番コストの大きいクリーチャー）
- 複数デッキの管理（新規・名前変更・複製・削除）
- 「テキストでコピー」（`4 カード名` 形式）／「インポート…」（カード名と一致したものを読み込む）／「共有リンク」（デッキ名・カード名と枚数を URL に詰める。PC はコピー、スマホは共有メニュー。サーバーは使わない）。スマホでもデッキのタブの上のほうにある

## 一人回し・対戦（play.html）
- 上部の「DECK BUILD／BATTLE」でデッキ作成と対戦を切り替え（対戦中のゲームは、戻ってくると続きから）。スマホでは元に戻す・リスタートはアイコンだけ
- スマホの戦場：シールドとマナを横に並べて1行にし（少しずつ重ねる。マナのタップは暗くして表す）、カードの大きさを戦場の高さから決めて、対戦でも相手と自分の盤面・手札が画面に収まるようにする
- 開始：山札をシャッフル → シールド5枚 → 手札5枚。先攻の1ターン目はドローしない（ネット対戦はマッチングしてから配る）
- フェイズ：ターン開始（自動でアンタップ）→ ドロー（自動）→ マナチャージ → メイン → 攻撃 → ターン終了
- ステップは自動で進む：マナチャージ・ステップでチャージ・召喚・呪文をするとメインへ、攻撃するとそのまま攻撃へ。チャージする手札がなければメインから始まる。攻撃し終えて攻撃できるクリーチャーがいなくなると、3秒後に自動でターン終了（「取り消し」でそのターンは止める。設定の AUTO で切れる）
- **ルールどおりにしか動かせない**：自分のターンの、そのステップでできることだけ。相手のターン・攻撃の結果待ち・効果の処理中は何もできない。手でカードを移す・引く・シャッフル・シールドを見る・前のフェイズに戻る・相手のターンを飛ばす（接続が切れたとき以外）はできない
- マナチャージ：マナチャージ・ステップに手札を1枚だけ（ドラッグ、または右クリック →「マナゾーンへ」）。チャージするとメインへ。マナゾーンのカードは上下逆さに置き、タップすると横向き。多色カードはタップして置く
- 召喚・呪文（マナチャージ・メイン・ステップだけ）：先にマナゾーンのカードをクリックしてタップし、支払うマナを選ぶ（青い枠）→ 手札をダブルクリック（またはバトルゾーンへドラッグ）。マナは自動では選ばない。選んだマナでコストの枚数と文明がそろわなければ出せない。選んだマナで払えるカードだけ明るく、ほかは暗くなる。選んだマナはクリックで外せるが、支払いに使ったマナはアンタップできない
- 呪文・S・トリガー：使うと画面いっぱいにカードと「SPELL!」「SHIELD TRIGGER!!」を出す演出（相手の画面にも出る）のあと、効果を処理する
- 召喚：バトルゾーンに出たカードは、大きく光りながら叩きつけるように着地して光の輪が広がり、戦場の中央に「SUMMON!」とカード名の帯が横切る（毎回・相手のカードも。呪文・S・トリガーの演出が出ているときは帯は出さない）
- チャット（ネット対戦）：ログに残すほか、フィールドの上を右から左へ流れる
- 呪文：唱えると戦場の中央（RESOLVING）に置かれる。効果を自動で処理したあと墓地へ。処理中はフェイズを進める・攻撃・ターン終了ができない（ネット対戦では相手の画面にも処理中の呪文が出る）
- 進化：進化クリーチャーを出すと、重ねるクリーチャーを選ぶ（先に選んだマナで払えるか確かめる）。進化元は一緒に移動し、「進化元N」と表示
- 攻撃：攻撃できるクリーチャーをクリック（マナチャージ・メイン・攻撃ステップ）→ プレイヤーか、相手のタップしているクリーチャーを選ぶ。攻撃を始めたら召喚・呪文はできない。召喚酔い（「Zz」）はスピードアタッカー・進化なら無し
  - ブロックされずプレイヤーへ：シールドをブレイカーの枚数ブレイク。シールドがなければダイレクトアタックで勝ち。ネット対戦では、割るシールドを相手のシールドをクリックして選ぶ（残りのシールドを全部割るときは選ばない）
  - クリーチャーとのバトル：パワーの大きいほうが勝ち、同じなら両方破壊（パワーアタッカーを足す、スレイヤー対応）
- シールド：裏向きのまま（中は見られない）。ブレイクされたシールドは1枚ずつ画面の中央に出して確認する（S・トリガーなら「使う／使わない」、それ以外は「確認」を押すまで止まる。S・トリガーがあったかどうかを待ち時間で悟られないよう、どのカードでも出す）。相手のログにはブレイクしたカードの名前を出さない（「使わない」を選んだことも出さない）。ネット対戦では、攻撃した側も相手が S・トリガー（とその呪文の処理）を終えるまで何もできない
- 仕込んだシールド：効果でシールドに加えたカードは、自分の画面だけ金色の枠と「仕込」の印（PC はカード名も）を付け、長押しで中身を見られる。エメラルなど効果でシールドを選ぶ画面でも、仕込んだカードには印とカード名を出す。相手には枚数しか送らない
- 負け：山札が0枚になる、ダイレクトアタックを受ける、投了
- 勝敗が決まると勝敗の画面を出し、閉じると毎回対戦準備画面（ゲームの開始）に戻る
- 一人回しでは、相手のシールド5枚を想定してブレイクした枚数を表示
- 山札・墓地：枚数を表示。墓地はクリックで一覧
- カードの詳細：カードを長押ししているあいだだけ表示し、離すと閉じる（PC・スマホとも）
- カードの移動（手札だけ）：バトルゾーンへ＝召喚・呪文、マナゾーンへ＝チャージ。PC はドラッグ、**スマホはカードに触れてそのまま指を動かし、置きたい場所で離す**（長押しはいらない）。手札は横に動かすとスクロール、縦に動かすとドラッグ
- 元に戻す（Ctrl+Z）、ショートカット：Space＝次へ、Enter＝ターン終了

## カードの効果の自動処理（effects.js）
基本編のカードの効果は、カードごとに自動で処理します。選ぶ必要があるときは「EFFECT」の画面が出て、カードを選んで「決定」（「〜してよい」は「使わない」も選べる）。

- 自動で処理するタイミング：呪文を唱えたとき（S・トリガーも）／クリーチャーがバトルゾーンに出たとき（召喚・進化・S・トリガー）／攻撃するとき（相手がブロックする前）／バトルゾーンから墓地に置かれたとき
- できること：カードを引く・山札をさがす・山札の上をマナ／シールド／手札へ・破壊・手札に戻す・マナ送り・タップ・手札を捨てさせる（見ないで選ぶ／相手が選ぶ／見て選ぶ）・相手のシールドや手札を見る・墓地やマナから回収・このターンだけの能力（パワー＋・W・ブレイカー・ブロックされない・タップされていないクリーチャーを攻撃できる など。バトルゾーンのカードに黄緑の印）
- 171種のカードが自動。ほかに、次の能力は効果テキストから読み取って自動で扱う：S・トリガー／ブロッカー／W・T・ブレイカー／スピードアタッカー／スレイヤー／パワーアタッカー+N、「攻撃できない」「プレイヤーを攻撃できない」「クリーチャーを攻撃できない」「ブロックされない」「パワー○○以下（以上）・闇（光）のクリーチャーにブロックされない」「タップされていないクリーチャーを攻撃できる」「バトルに勝っても墓地に置かれる」「相手プレイヤーを攻撃したあと墓地に置かれる」「墓地に置くかわりに手札・マナ・シールドへ」「ターンの終わりにアンタップ」「ブロックしたあとアンタップ」、進化クリーチャー
- ネット対戦：相手のカードを動かす効果は相手の画面に反映され、相手が選ぶ効果（「相手は自分のクリーチャーを1体選び…」など）は相手の画面で選ぶ画面が出る。一人回しでは相手に関する効果は省略
- 常在型能力も自動：
  - パワーの増減（「攻撃中」は攻撃のときだけ）・能力を与える（ブロッカー・W・ブレイカー・ブロックされない など）。盤面から毎回計算し、パワーが変わったカードには右上に赤い数字
  - コストの増減（ミリエス・ヘル・スモーク・ミサイルボーイ・カスミダケ・角男は両方のプレイヤーに、エルフィンは自分に）。マナの自動支払いと手札の暗い表示に反映
  - 制限：アルカディアス（光以外の呪文を唱えられない）、フ・レイル・ギガボルバ（その文明の S・トリガーが使えない）、毎ターン攻撃しなければならない・ファントム・ベール（攻撃しないとターン終了できない）、ヴァシュナ・ギガゾウル・ブルレイザー（条件つきで攻撃できない）、「○○のクリーチャーに攻撃されない」、「火・自然ブロッカー」「自然・光スレイヤー」「光クリーチャーとのバトルに負けても墓地に置かれない」
  - 移動に合わせて働く能力：ギガマンティス（自然のクリーチャーをマナへ）、ポッポ・チャッピー（アーマード・ドラゴンの身代わり）、ジャックバイパー（闇のクリーチャーを手札へ戻してよい）、ミスト・リエス・屑男（ほかのクリーチャーが出た・墓地に置かれたら引いてよい。相手のクリーチャーも数える）、シュノーク・ラー（相手の効果で墓地へ行くマナを戻してよい）
  - そのほか：ポコルル（相手が S・トリガーを使ったらアンタップしてよい）、神拳の超人（ブロックされたらシールドを1枚ブレイク）、ビースト・チャージ（ターン終了時にブレイクした枚数だけクリーチャーをさがす）、シェル・ポーチ（相手の進化クリーチャーの一番上を墓地へ）
- 効果を足すときは `effects.js` の `FX`（タイミングごとの効果：`cast`・`summon`・`attack`・`death`・`otherEnter`・`otherDie`）、`FX_SELF`・`FX_AURA`（常在型のパワー・能力）、`FX_COST_UP`（コスト）にカード名で書く

## ネット対戦
- 開始画面で「部屋を作る」→ 表示された部屋コード（6桁の数字）を相手に伝え、相手は「部屋に入る」で入力
- マッチングするまでは専用のマッチング画面（自分と相手のアバター・部屋コード・接続状況・「やめる」）を出す。相手が見つかると「MATCH!」の演出のあと対戦が始まる
- PeerJS（無料の公開サーバー）でブラウザ同士をつなぎます。URL に `?local=1` を付けると、同じPCの別タブ同士で試せます
- 攻撃は1回ずつ：攻撃すると相手の画面にブロックの選択（ブロッカーのボタン／ブロックしない）が出て、結果が自動で反映されます。ブロックできるクリーチャーがいなければ自動で「ブロックしない」
- ブロック・S・トリガーは守る側だけが決めます。その間、攻撃した側はカードを出す・動かす・タップ・次の攻撃・ターン終了ができません（相手との接続が切れたときだけ「ブロックなしで進める」「待たずに進める」が出る）
- マッチング：部屋を作った人と入った人が同じ対戦に入るまでは、手札・シールドを配らず、盤面は操作できません（「対戦相手を待っています」）。マッチングすると「MATCH!」→ 両方に手札・シールドを配る →「先攻」「後攻」を大きく発表 → 1ターン目が始まる

## 設定（右上の歯車）
- 開いたときは名前の欄を自動で編集状態にしない（スマホでキーボードが出ない）
- プレイヤー名（未入力なら「プレイヤー」）・アバター・サウンド（BGM と SE＝効果音を、それぞれスイッチでオン・オフ、つまみで音量）・戦場の背景（グリッド・ギャラクシー・サーキット・ステージ・ミッドナイト。一人回し・対戦画面のみ）・自動でターン終了のオン・オフ（一人回し・対戦画面のみ）
- バックアップ：全デッキと設定を1つの JSON ファイルに保存／読み込み（読み込むと置き換わる）

## デザイン
- Y2K アーケード風（ネオンの黄緑と青、シルバーの帯、角の丸いパネル）。大きな見出しは英語＋小さな日本語
- 背景で回るリング・流れる線・流れる帯の文字。パネル・ダイアログ・メニュー・お知らせ・スマホのタブとシートには出てくるときのアニメーション。画面の切り替え（デッキ選択⇔編集⇔対戦）は、斜めのパネル（黄緑・青・紺）が画面を横切ってロゴを出すワイプ
- 軽くするため、アニメーションは transform と opacity だけを動かし、ぼかし（backdrop-filter）は使わない。端末の「視差効果を減らす」設定ではアニメーションを止める
- 戦場の背景・アイコンは画像を使わず CSS と SVG で描いている
- フォントは Google Fonts（M PLUS Rounded 1c・Russo One）

## 注意
- 非公式のファンツールです。株式会社タカラトミー・Wizards of the Coast とは関係ありません
- アバター（`img/avatar/`）にはほかの作品のキャラクターが含まれるので、公開する場合は差し替えを推奨します

## 文明のアイコン（img/civ/）
光・水・闇・火・自然の5つのアイコン（`light.svg` など。白一色の SVG）を、背景の飾りに使っています（ボタンには使わない）。CSS の mask で色と透明度を付けます。
- 画面全体の背景：5つがゆっくり漂う／上部の流れる帯：区切りの記号／パネル：右下に薄い透かし（パネルごとに替わる）
- 戦場：5つを横一列に並べた薄い透かし（`band.svg`）／マッチング画面：レーダーのまわりを回る／「ゲームの開始」画面：後ろに薄い帯（`band-faint.svg`）

## BGM（bgm/）
画面ごとに `bgm/<名前>.mp3` をくり返し流します（ブラウザが自動再生を止めたときは、画面に最初に触れたときから）。曲の頭の無音と終わりの消えかけ（フェードアウト）を自動で削り、終わりの3秒を次の周の頭と重ねてクロスフェードし、切れ目なくループします（Web Audio。`index.html` を直接開いたときはふつうのループ）。タブが見えていない間は止まります。差し替えるときは同じ名前で置き換えてください。
曲が変わるとき（デッキ選択⇔編集）は今の曲をフェードアウトしながら次の曲をフェードインし、別のページへ移るとき（対戦へ・デッキ作成へ）は曲をフェードアウトしてから移ります。

| 名前 | 画面 | 曲 |
|---|---|---|
| select | デッキ選択 | State Of The Art |
| edit | デッキ編集 | evergreen |
| ready | 対戦の準備（開始画面・相手待ち・1ターン目の前）。頭の1秒を削って流す | beatonic nation |
| battle | 対戦中（3曲から対戦ごとにランダム） | Hybrid Landscape |
| battle-cyber-girl | 〃 | Cyber girl |
| battle-all-is-vanity | 〃 | All is vanity |

対戦中の曲は、1回の対戦ごとに3曲からランダムで選び、対戦が始まってから10秒ほど画面の右上の端に「♪ 曲名」と出します（BGM がオフのときは出さない）。曲を足すときは `play.js` の `BATTLE_BGM` に追加してください。

※ 曲はユーザーが用意したファイルです。公開する場合は、曲の利用条件を確認してください。

## 効果音（sounds/）
`sounds/<名前>.mp3`（なければ `<名前>.wav`）を鳴らします。ファイルがない音は鳴りません。
今は仮の音として、Y2K風の未来っぽい電子音（キラキラした FM ベル・厚いシンセ・レーザー・ビットクラッシュのグリッチ・デジタルのエコー）で作った `.wav` が入っています（`tools/gen_sounds_y2k.py` で作り直せます：`py tools/gen_sounds_y2k.py sounds`）。音を差し替えたら、`sound.js` の `VERSION` を上げるとブラウザに残った古い音を使いません。本番の音は同じ名前の `.mp3` を置けばそちらが優先されます（`.wav` は消しても構いません）。

| 名前 | 鳴る場面 |
|---|---|
| draw | カードを引く |
| shuffle | 山札をシャッフル（ゲーム開始時も） |
| tap / untap | カード・マナをタップ／アンタップ（召喚でマナを支払うときも tap） |
| summon | クリーチャーを召喚 |
| evolve | 進化クリーチャーを出す |
| spell | 呪文を唱える（手札から墓地へ） |
| trigger | S・トリガーを使う |
| field | クリーチャー以外（クロスギア・城など）をバトルゾーンに出す |
| mana-light / mana-water / mana-dark / mana-fire / mana-nature | 光／水／闇／火／自然のカードをマナチャージ |
| mana-multi | 多色のカードをマナチャージ |
| attack | 自分のクリーチャーで攻撃 |
| attacked | 相手に攻撃された（ネット対戦） |
| block | ブロックした |
| break | シールドをブレイク（された） |
| destroy | クリーチャーが破壊された（バトルゾーンから墓地へ） |
| discard | 手札などから墓地へ |
| phase | フェイズが進む |
| myturn | 自分のターンが来た（ネット対戦） |
| endturn | ターン終了 |
| win / lose | 勝利／敗北 |
| button | ボタン・リンク・タブ・デッキのタイルを押す、設定の操作、音量の確認 |
| cancel | 取り消し・元に戻す・できない操作のお知らせ、デッキにそれ以上入れられないカード |
| open | メニュー・ダイアログ（設定・殿堂・インポートなど）を開く |
| close | ダイアログを閉じる |
| card-add | デッキにカードを1枚入れる |
| card-remove | デッキからカードを1枚抜く |
| page | 画面の切り替え（ワイプ） |

長押しで出すカードの詳細は頻繁に開くので、open / close は鳴らしません。勝敗のダイアログは win / lose だけ鳴らします。

## ファイル
- `index.html` / `app.js` / `style.css`：デッキ作成
- `play.html` / `play.js` / `play.css`：一人回し・ネット対戦（`play.css` にアイコンの SVG）
- `cards.js`：カードのデータ（文明・能力の読み取り・カードの表示・殿堂・保存）
- `classic-cards.js`：収録カード（クラシック基本編）
- `effects.js`：カードの効果の自動処理（カードごとの効果・選ぶ画面・ネット対戦での受け渡し）
- `settings.js`：設定画面、`sound.js`：効果音、`net.js`：通信、`felt.js`：戦場の背景の選択、`device.js`：スマホ判定、`zoom.js`：長押しの拡大表示
- `theme.css`：共通の部品と戦場の背景
- `skin.css`：デザインとアニメーション
- `img/avatar/`・`sounds/`・`bgm/`：アバター・効果音・BGM
- `tools/gen_sounds_y2k.py`：仮の効果音を作るスクリプト（Python 3。追加のライブラリは不要）
