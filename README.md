# デュエマ System

デュエル・マスターズのデッキ作成・一人回し・ネット対戦ができる静的 Web アプリです（非公式のファンツール）。
**DM-01〜30 の時代（旧枠）のカードが収録済み**です（`classic-cards.js`）。ブラウザ内（localStorage）に保存するのはデッキと設定だけです。

`index.html` を開くだけで動きます（サーバー不要。GitHub Pages などにそのまま置けます）。

## 収録カード
- DM-01〜DM-30、DMC-20・21・27・34・42、プロモ1〜7期のカードを、[デュエル・マスターズ公式サイトのカード検索](https://dm.takaratomy.co.jp/card/)から取得しました（同名カードは1種類にまとめ、最初に収録された弾を「初出」にしています）
- 画像は公式サイトの画像を直接表示します（アプリには画像を入れていません。表示にはネット接続が必要）。読み込むまでは、文明の色の枠にコスト・名前・パワーを書いたカードを出します
- 公式サイトのサイトポリシーでは、個人的な使用や非営利目的の使用は認められています。それ以外の目的で使ったり、データを再配布したりする場合は権利者の許諾が必要です
- 公式のデータベースにない DMC-01〜19 の構築済みデッキのカードは、ほかの弾で再録されていなければ入っていません。《凶星王ダーク・ヒドラ》は初出の DMC-13 の代わりに DMC-38 の再録の情報と画像で入れています
- プロモの初出の時代は「期」から大まかに決めています（1期＝基本編、2〜4期＝〜2005年、5〜7期＝〜2008年）
- カードの登録・編集の機能はありません（収録カードだけを使います）
- 効果テキストから次の能力を読み取り、対戦で自動的に扱います：S・トリガー／ブロッカー／W・T・ブレイカー／スピードアタッカー／スレイヤー／パワーアタッカー+N、「攻撃できない」「プレイヤーを攻撃できない」「ブロックされない」、進化クリーチャー

## フォーマット（デュエマクラシック）
デッキごとに「フリー（制限なし）」「クラシック基本編」「クラシック05」「クラシック08」を選べます。クラシックはコミュニティで決められた非公式のレギュレーションです。

| フォーマット | 使えるカード（同名カードの初版で判定。再録版でも同じ） |
|---|---|
| クラシック基本編 | DM-01〜05・DMC-01〜04と同時期のプロモ |
| クラシック05 | 2005年までに初版が出たカード（DM-16まで。DM-17・DMC-27以降は不可） |
| クラシック08 | 2008年までに初版が出たカード（DM-30「戦極魂」まで。超次元ゾーンなし） |

- 殿堂（制限＝1枚まで・禁止＝0枚・お助けカード＝一覧から合計1枚まで・同時投入禁止の組）は、3つのフォーマットとも既定の一覧が入っています（`cards.js` の `REGULATIONS`）。改定されたら「殿堂…」で書き換えられ、「既定に戻す」で戻せます
- 「デッキのフォーマットで使えるカードだけ」で、カード一覧を絞り込めます。使えないカードは暗く表示します

## デッキ作成（index.html）
- カードをクリックで追加、右クリックで1枚減らす。PC はマウスを乗せるとカードを大きく表示。スマホは長押しで拡大表示と追加・減らす
- 40枚ちょうど・同じカードは4枚まで（違反は警告）
- 文明ごとの枚数、内訳（S・トリガー・ブロッカー・クリーチャー・呪文・その他の枚数）、コストの分布を表示
- デッキリストの並び順：種類順・コスト順・文明順（デッキごとに記憶）。リストは右側のパネルの中でスクロール
- レギュレーションのバッジ：採用カードの初出から、デッキが入る一番狭いクラシックのフォーマット（基本編→05→08）を表示。殿堂の違反があれば件数も出す。今のフォーマットと違えば、押すとそのフォーマットに切り替わる
- 複数デッキの管理（新規・名前変更・複製・削除）
- 「テキストでコピー」（`4 カード名` 形式）／「インポート…」（カード名と一致したものを読み込む）／「共有リンク」（デッキ名・フォーマット・カード名と枚数を URL に詰める。PC はコピー、スマホは共有メニュー。サーバーは使わない）。スマホでもデッキのタブの上のほうにある

## 一人回し・対戦（play.html）
- 開始：山札をシャッフル → シールド5枚 → 手札5枚。先攻の1ターン目はドローしない
- フェイズ：ターン開始（自動でアンタップ）→ ドロー（自動）→ マナチャージ → メイン → 攻撃 → ターン終了
- マナチャージ：手札を右クリック →「マナゾーンへ」かドラッグ（1ターン1枚。超える場合は確認）。マナゾーンのカードは上下逆さに置き、タップすると横向き。多色カードはタップして置く
- 召喚・呪文：手札をダブルクリック。必要な文明を含めてマナを自動でタップ（足りなければ確認して支払わずに出せる）。呪文は墓地へ（効果は手で処理）
- 進化：進化クリーチャーを出すと、重ねるクリーチャーを選ぶ。進化元は一緒に移動し、「進化元N」と表示
- 攻撃：攻撃できるクリーチャーをクリック（メインからでも可）→ プレイヤーか、相手のタップしているクリーチャーを選ぶ。召喚酔い（「Zz」）はスピードアタッカー・進化なら無し
  - ブロックされずプレイヤーへ：シールドをブレイカーの枚数ブレイク。シールドがなければダイレクトアタックで勝ち
  - クリーチャーとのバトル：パワーの大きいほうが勝ち、同じなら両方破壊（パワーアタッカーを足す、スレイヤー対応）
- シールド：クリックでメニュー（ブレイク・中を見る・移動）。ブレイクされたシールドに S・トリガーがあれば「使う／使わない」を選ぶ
- 負け：山札が0枚になる、ダイレクトアタックを受ける、投了
- 一人回しでは、相手のシールド5枚を想定してブレイクした枚数を表示
- 山札：クリックで1枚ドロー、右クリックでX枚ドロー・シャッフル・上から見る・探す・上からマナ／墓地へ・シールド追加
- カードの移動：PC は右クリックメニューかドラッグ。**スマホはカードを長押しして、そのまま指を動かし、置きたい場所（バトルゾーン・シールド・マナ・手札・山札・墓地）で離す**。動かさずに離すと拡大表示
- 元に戻す（Ctrl+Z）、ショートカット：Space＝次へ、Enter＝ターン終了、D＝1枚引く

## ネット対戦
- 開始画面で「部屋を作る」→ 表示された部屋コードを相手に伝え、相手は「部屋に入る」で入力
- PeerJS（無料の公開サーバー）でブラウザ同士をつなぎます。URL に `?local=1` を付けると、同じPCの別タブ同士で試せます
- 攻撃は1回ずつ：攻撃すると相手の画面にブロックの選択（ブロッカーのボタン／ブロックしない）が出て、結果が自動で反映されます。相手が応答しないときは「ブロックなしで進める」
- 先攻・後攻は部屋を作った人が決めます

## 設定（右上の歯車）
- プレイヤー名（🎲でランダム）・アバター・効果音のオン・オフと音量・戦場の背景（グリッド・ギャラクシー・サーキット・ステージ・ミッドナイト。一人回し・対戦画面のみ）
- バックアップ：全デッキと設定を1つの JSON ファイルに保存／読み込み（読み込むと置き換わる）

## デザイン
- Y2K アーケード風（ネオンの黄緑と青、シルバーの帯、角の丸いパネル）。大きな見出しは英語＋小さな日本語
- 背景で回るリング・流れる線・流れる帯の文字。ページの移動・パネル・ダイアログ・メニュー・お知らせ・スマホのタブとシートには出てくるときのアニメーション（ページの移動は対応するブラウザのみ）
- 軽くするため、アニメーションは transform と opacity だけを動かし、ぼかし（backdrop-filter）は使わない。端末の「視差効果を減らす」設定ではアニメーションを止める
- 戦場の背景・アイコンは画像を使わず CSS と SVG で描いている
- フォントは Google Fonts（M PLUS Rounded 1c・Russo One）

## 注意
- 非公式のファンツールです。株式会社タカラトミー・Wizards of the Coast とは関係ありません
- アバター（`img/avatar/`）にはほかの作品のキャラクターが含まれるので、公開する場合は差し替えを推奨します

## 効果音（sounds/）
`sounds/<名前>.mp3`（なければ `<名前>.wav`）を鳴らします。ファイルがない音は鳴りません。

| 名前 | 鳴る場面 |
|---|---|
| draw | カードを引く |
| shuffle | 山札をシャッフル（ゲーム開始時も） |
| tap / untap | カード・マナをタップ／アンタップ（召喚でマナを支払うときも tap） |
| summon | クリーチャーを召喚 |
| evolve | 進化クリーチャーを出す |
| spell | 呪文を唱える（手札から墓地へ） |
| trigger | S・トリガーを使う |
| field | クリーチャー以外（クロスギア・城など）をバトルゾーンに出す |
| mana-light / mana-water / mana-dark / mana-fire / mana-nature | 光／水／闇／火／自然のカードをマナチャージ |
| mana-multi | 多色のカードをマナチャージ |
| attack | 自分のクリーチャーで攻撃 |
| attacked | 相手に攻撃された（ネット対戦） |
| block | ブロックした |
| break | シールドをブレイク（された） |
| destroy | クリーチャーが破壊された（バトルゾーンから墓地へ） |
| discard | 手札などから墓地へ |
| phase | フェイズが進む |
| myturn | 自分のターンが来た（ネット対戦） |
| endturn | ターン終了 |
| win / lose | 勝利／敗北 |
| button | ボタン・設定の操作、効果音のオン、音量の確認 |
| cancel | 取り消し・元に戻す・できない操作のお知らせ |

## ファイル
- `index.html` / `app.js` / `style.css`：デッキ作成
- `play.html` / `play.js` / `play.css`：一人回し・ネット対戦（`play.css` にアイコンの SVG）
- `cards.js`：カードのデータ（文明・能力の読み取り・カードの表示・フォーマットと殿堂・保存）
- `classic-cards.js`：収録カード（DM-01〜30 の時代）
- `settings.js`：設定画面、`sound.js`：効果音、`net.js`：通信、`felt.js`：戦場の背景の選択、`device.js`：スマホ判定、`zoom.js`：長押しの拡大表示
- `theme.css`：共通の部品と戦場の背景
- `skin.css`：デザインとアニメーション
- `img/avatar/`・`sounds/`：アバター・効果音
